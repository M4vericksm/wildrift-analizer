# Decisões de arquitetura (ADRs)

Cada arquivo aqui registra uma decisão técnica: o contexto que a motivou, o
que foi decidido, e as consequências/riscos assumidos. Antes de propor mudar
uma decisão já registrada, leia o ADR correspondente — só reabra a
discussão se o contexto descrito nele tiver mudado de fato.

Formato: `NNNN-titulo-curto.md`, sempre com as seções Contexto, Decisão,
Consequências.
